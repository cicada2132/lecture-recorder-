# lecture-recorder

**녹화 컴퓨터와 입력(재생) 컴퓨터를 분리해서, 여러 개의 인강을 자동으로 연속 녹화하는 프로그램**

[AutoHotkey v2](https://www.autohotkey.com/) 스크립트 두 개로 이루어져 있습니다.
한 컴퓨터는 강의를 재생하고 다음 강의로 넘기는 키 입력만 담당하고,
다른 컴퓨터는 OBS로 화면을 녹화만 담당합니다.
두 스크립트는 네트워크 통신 없이 **같은 시간표(타이머)** 로 돌아가기 때문에,
처음에 한 번만 시작 시점을 맞춰 주면 끝까지 자동으로 동기화됩니다.

| 파일 | 실행 위치 | 역할 |
|---|---|---|
| [`multivar_auto_next.ahk`](multivar_auto_next.ahk) | **재생(입력) 컴** | 강의 재생시간이 끝나면 키 시퀀스를 보내 다음 강의를 열고 광고를 넘김 |
| [`multivar_obs_record.ahk`](multivar_obs_record.ahk) | **녹화 컴** | 강의마다 OBS 녹화를 켜고 끄며, 녹화 파일 이름을 강의명으로 바꿈 |

---

## 왜 컴퓨터를 나누나요?

- 강의 사이트 플레이어가 화면 녹화 프로그램을 감지하거나, 같은 컴에서 녹화하면 재생이 끊기는 문제를 피할 수 있습니다.
- 재생 컴은 키 입력만, 녹화 컴은 캡처(캡처보드 등)·인코딩만 하므로 부하가 분산됩니다.
- 한 강의마다 파일이 따로 저장되고, 강의 사이 대기 구간은 녹화되지 않습니다.

## 동작 원리 (싱크 구조)

두 스크립트는 강의 1개당 **완전히 같은 길이의 주기**로 돌아갑니다.

```
재생 컴 : [ 강의 재생 (원본 ÷ 배속) ][ 대기 50초 ][ 키 시퀀스 10초 ] → 다음 강의
녹화 컴 : [ 강의 재생 (원본 ÷ 배속) ][ 뒤여유 30초 ][ 녹화 정지 30초 ] → 다음 녹화
           ●──────────── 녹화 ON ──────────────────● ○── OFF ──○
```

- 주기 = `재생시간 + BufferSec(50) + SeqSec(10)` = `재생시간 + PostRoll(30) + 정지(30)`
- 재생 컴이 마지막 `{RIGHT}`(광고 스킵)를 누르는 순간 = 녹화 컴이 녹화를 켜는 순간
- 강의 길이는 스크립트 안의 강의 목록(원본 분)과 배속으로 계산합니다.

재생 컴이 보내는 키 시퀀스:

```
{CTRL}W {WAIT:1} {TAB} {WAIT:1} {ENTER} {WAIT:1} {ENTER} {WAIT:6} {ENTER} {WAIT:1} {RIGHT}
 탭 닫기            다음 강의 선택/열기               로딩 대기   재생       광고 스킵
```

## 준비물

- 두 대의 Windows PC (AutoHotkey **v2.0** 설치)
- 녹화 컴: [OBS Studio](https://obsproject.com/) + 재생 컴 화면을 받아올 방법 (캡처보드, NDI 등)

## 사용법

### 1. OBS 설정 (녹화 컴)

OBS `설정 → 단축키` 에서 스크립트와 같은 키를 지정합니다.

| 동작 | 기본 키 |
|---|---|
| 녹화 시작 | `Pause` |
| 녹화 중지 | `ScrollLock` |

> 조합키는 OBS가 놓치는 경우가 있어서 단일키를 권장합니다.
> 토글 하나만 쓰려면 `KeyStop := ""` 로 비워 두세요.

### 2. 설정값 맞추기

두 스크립트 상단의 **설정** 부분에서 아래 값은 반드시 **양쪽이 같아야** 합니다.

| 변수 | 기본값 | 의미 |
|---|---|---|
| `Speed` | `1.5` | 재생 배속 |
| `BufferSec` | `50` | 강의 종료 후 다음 강의까지 대기(초) |
| `SeqSec` | `10` | 키 시퀀스 총 소요 시간(초). 재생 컴의 `WaitScale` 을 바꾸면 같이 바꿀 것 |
| `StartIndex` | — | 목록 몇 번째 강의부터 시작할지 (`1` = 0강) |

녹화 컴 전용 설정:

| 변수 | 기본값 | 의미 |
|---|---|---|
| `StartDelay` | `10` | 시작 카운트다운(초) |
| `PreRoll` | `0` | 강의 시작 전 미리 녹화(초). OBS 인코더 시작 지연으로 앞 1~2초가 잘리면 `2` 로 |
| `PostRoll` | `30` | 강의 끝난 뒤 더 녹화(초) |
| `RecDir` | — | OBS 녹화 저장 폴더. 지정하면 녹화 파일을 `N강 강의제목` 으로 자동 이름 변경 |

재생 컴 전용 설정:

| 변수 | 기본값 | 의미 |
|---|---|---|
| `WaitScale` | `1.0` | 키 사이 대기 배율. 페이지 로딩이 느리면 `1.5~2.0` |
| `TargetWin` | `""` | 키를 보낼 창 (예: `"ahk_exe chrome.exe"`). 비우면 활성 창 |
| `SendOnLast` | `false` | 마지막 강의 후에도 다음 강의를 열지 여부 |

### 3. 시작

1. **재생 컴**: 브라우저에서 첫 강의를 열고 광고를 넘긴 뒤, 배속을 맞추고 **영상 맨 앞에서 일시정지**
2. **재생 컴**: `multivar_auto_next.ahk` 실행
3. **녹화 컴**: `multivar_obs_record.ahk` 실행 → `Ctrl+Alt+S` → 10초 카운트다운 시작
4. 카운트가 **0 이 되는 순간** 재생 컴에서 영상 재생 + `F9`

이후에는 마지막 강의까지 자동으로 진행됩니다.
각 스크립트 GUI 창에 현재 강의, 남은 시간, 전체 종료 예상 시각이 표시됩니다.

## 단축키

### 재생 컴 (`multivar_auto_next.ahk`)

| 키 | 동작 |
|---|---|
| `F9` | 시작 / 일시정지 |
| `F10` | 지금 바로 다음 강의로 (키 시퀀스 전송) |
| `F11` | 이전 강의로 되돌리기 |
| `F12` | 현재 강의 타이머 리셋 |
| `Ctrl+Alt+↑ / ↓` | 키를 보내지 않고 목록만 이동 |
| `Ctrl+Alt+← / →` | 남은 시간 10초 당기기 / 미루기 (싱크 보정) |
| `Ctrl+Alt+Q` | 종료 |

### 녹화 컴 (`multivar_obs_record.ahk`)

| 키 | 동작 |
|---|---|
| `Ctrl+Alt+S` | 시작 / 일시정지 |
| `Ctrl+Alt+N` | 지금 바로 다음 단계로 |
| `Ctrl+Alt+← / →` | 남은 시간 10초 당기기 / 미루기 (싱크 보정) |
| `Ctrl+Alt+Q` | 녹화 중지 후 종료 |

> 녹화 컴 단축키는 OBS 핫키와 겹치지 않도록 모두 조합키로 되어 있습니다.

## 이어서 녹화하기

강의가 많으면 며칠에 나눠 녹화하게 됩니다. 두 스크립트의 `StartIndex` 를 **같은 값**으로 맞추고
위 [시작](#3-시작) 순서를 다시 따르면 됩니다. (`1` = 0강, `2` = 1강, …)
재생 컴은 실행 후 `Ctrl+Alt+↓` 로 목록만 원하는 강의까지 옮겨도 됩니다.

## 다른 강의에 쓰기

두 스크립트의 `lectures` 목록만 바꾸면 됩니다. 형식은 `[강번호, "제목", 원본 길이(분)]` 이며,
**두 파일의 목록이 똑같아야** 싱크가 맞습니다. 강의 사이트 구조가 다르면 재생 컴의
`SendSequence()` 함수에서 키 순서를 수정하세요 (대기 시간을 바꾸면 `SeqSec` 도 같이 수정).

## 싱크가 어긋났을 때

- 조금씩 밀리면 `Ctrl+Alt+← / →` 로 10초 단위 보정
- 크게 어긋나면 양쪽을 일시정지하고, 해당 강의를 `StartIndex` 로 지정해 다시 시작
- 페이지 로딩이 불안정하면 `WaitScale` 을 늘리고, 그에 맞게 녹화 컴 `SeqSec` 도 늘리기

## 주의

개인 학습 목적의 녹화에만 사용하세요. 녹화한 강의를 배포하거나 공유하는 것은
강의 제공처의 이용약관 및 저작권법에 위배될 수 있습니다.
